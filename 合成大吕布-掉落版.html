📜 游戏规则

目标：掉落武将，两个相同武将相碰即合成下一级，最终合成传说中的 🔱 大吕布！合成吕布后可以继续刷分。
操作：按住拖动（或移动鼠标）瞄准，松开手武将垂直落下。手机触屏同样支持。
掉落池：只会随机掉落前 5 级（孙尚香 / 蔡文姬 / 曹操 / 赵云 / 刘禅），马超以上全靠合成。
合成链（共 11 级）：孙尚香 → 蔡文姬 → 曹操 → 赵云 → 刘禅 → 马超 → 貂蝉 → 小乔 → 甄姬 → 周瑜 → 吕布。
计分：合成第 n 级得 n×(n+1)/2 分，合成大吕布额外 +100。
失败：场上有武将持续越过顶部红色警戒线约 1.5 秒，游戏结束。
小技巧：像 2048 一样把大武将排角落、同级相邻放置；耐心等球落定再放下一个；也可以用新球把两个同级武将"挤"到一起。
